# Dreem Sabiniano — Portfolio

Responsive single-page portfolio built from the supplied files. It keeps the cream, blush, and pink theme, with a sales-focused layout, concise service cards, motion, project previews, and an interactive VA fit check.

## Included
- Six services; categorized tools and an automatically scrolling tools list
- Six project cards with live previews and expandable Problem, Findings, and Result notes
- “Do you need a VA?” check, three-step working process, three-sentence about section, and contact CTA
- Sticky “Book an intro call,” parallax accents, hover motion, and reduced-motion support
- Local PDF previews inside the site; Notion and Google Drive previews open in a new tab

## Personalize
1. Your about portrait and both Notion project screenshots are included. Replace those files in this folder whenever you update the images.
2. The Notion project cards use `pool-sauna.png` and `brooks-calendar.png`; the cards link to their live Notion pages.
3. The booking buttons are connected to your Calendly intro call.
4. Confirm the Notion and Drive sharing settings and check PDF previews after publishing.

Open `index.html` directly or serve this folder with a static web server. No build step or JS library is needed.
